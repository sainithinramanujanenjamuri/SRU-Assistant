# Document Storage Directory

This directory stores institutional academic documents for SRU Assistant.

## Structure

- `raw/`: Unmodified original documents sourced from SR University (e.g., syllabi PDFs, academic calendar DOCX files, exam guidelines, department notices). Files in this directory should never be modified in-place.
- `processed/`: Extracted text, cleaned markdown representations, and structured JSON files generated by the ingestion pipeline during later phases.

## Guidelines

- Do not commit large or private PDF/DOCX files to the repository. The `.gitignore` excludes document contents by default.
- Real document ingestion and text extraction will be implemented in **Phase 1: Document Intelligence**.
